Introduction

REST API for SupportHub — ticket creation and lifecycle, routing, SLA, notifications, and administration. Backs the web, mobile and any third-party clients equally; this document is the contract.

Base URL: http://localhost:8000 
This documentation aims to provide all the information you need to work with our API.

<aside>As you scroll, you'll see code examples for working with the API in different programming languages in the dark area to the right (or as part of the content on mobile).
You can switch the language used with the tabs at the top right (or from the nav menu at the top left on mobile).</aside>

Authenticating requests

To authenticate requests, include an Authorization header with the value "Bearer {YOUR_AUTH_TOKEN}".

All authenticated endpoints are marked with a requires authentication badge in the documentation below.

Obtain a token from POST /api/v1/auth/login or POST /api/v1/auth/register, then send it as Authorization: Bearer {token} on every subsequent request.

Authentication

Token-based authentication shared by the web, mobile and third-party clients. All endpoints here are unauthenticated except /auth/logout, /auth/me and the email verification resend endpoint, which require a Bearer token obtained from /auth/login or /auth/register.

Register (customer self-service)

Creates a new Customer-role account and an associated customer profile, then returns a Bearer token. A verification email is queued automatically.

Example request:
curl --request POST \
    "http://localhost:8000/api/v1/auth/register" \
    --header "Content-Type: application/json" \
    --header "Accept: application/json" \
    --data "{
    \"name\": \"Jamie Rivera\",
    \"email\": \"jamie@example.com\",
    \"password\": \"Secret123!\",
    \"phone\": \"+1-555-0100\",
    \"company_name\": \"Acme Corp\",
    \"device_name\": \"z\",
    \"password_confirmation\": \"Secret123!\"
}"

const url = new URL(
    "http://localhost:8000/api/v1/auth/register"
);

const headers = {
    "Content-Type": "application/json",
    "Accept": "application/json",
};

let body = {
    "name": "Jamie Rivera",
    "email": "jamie@example.com",
    "password": "Secret123!",
    "phone": "+1-555-0100",
    "company_name": "Acme Corp",
    "device_name": "z",
    "password_confirmation": "Secret123!"
};

fetch(url, {
    method: "POST",
    headers,
    body: JSON.stringify(body),
}).then(response => response.json());
