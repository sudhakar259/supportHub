# DeskZeal interface font

DM Sans is served locally for the public website and authenticated workspace.
The normal variable WOFF2 subsets support weights 400–800; body text uses 500,
labels use 600, and headings use 700. The browser handles optical sizing.

Source: [Google Fonts DM Sans](https://github.com/google/fonts/tree/main/ofl/dmsans).
The Latin and Latin Extended files were obtained from the
[Google Fonts stylesheet](https://fonts.googleapis.com/css2?family=DM+Sans:opsz,wght@9..40,400..800&display=swap).
See `DM-Sans-OFL.txt` for the included SIL Open Font License.

Only the Latin subset is preloaded; Latin Extended loads when needed.
System sans-serif fonts provide fallback for other scripts. Material Symbols
and JetBrains Mono retain their existing separate font loading.
